== The Core Issue: OpenAPI Spec Not Connected to Pennie

=== What's Wrong
Your screenshot shows Pennie called `read_projects()` but got empty output. The backend returns data correctly when tested with curl (26 projects), but Pennie doesn't receive the data.

=== Why This Happens
**Pennie has the function schema but not the HTTP endpoint URL.** She knows the function signature but doesn't know WHERE to send the HTTP request.

In Azure AI Foundry, when you add an "Action", you must provide:
1. Function name and parameters (schema) ✅ You have this
2. HTTP endpoint URL ❌ This is missing or incorrect

=== The Fix
The OpenAPI spec at `/mnt/raid1/GitHub/GetPenn.ie/openapi/pennie-backend-openapi.json` contains all 9 function definitions WITH the correct endpoint URLs.

This spec needs to be added to Pennie as an Action in the Azure AI Foundry portal.

**Backend URL**: `https://pennie-backend-prod.azurewebsites.net`

All 9 functions are operational and return HTTP 200 responses.

== Python SDK Issues

=== OpenApiTool Not JSON Serializable
**Error:** `TypeError: Object of type OpenApiTool is not JSON serializable`

**Cause:** Bug in azure-ai-agents SDK v1.0.0

**Workaround:** Use REST API directly instead of Python SDK (see scripts/update-pennie-tools.sh)

---

== Backend Deployment Issues

=== Windows vs Linux Function App
**Problem:** Functions return HTTP 503 "Function host is not running"

**Cause:** Python Azure Functions MUST run on Linux, not Windows

**Fix:** Deploy with `kind: 'functionapp,linux'` and `linuxFxVersion: 'Python|3.11'` in Bicep

== How to Fix Pennie (Manual Portal Steps Required)

Since the Python SDK has bugs and REST API for adding Actions is not documented, the current solution requires adding the OpenAPI spec via the Azure AI Foundry portal:

1. Open https://ai.azure.com/resource/agentsList
2. Select "Pennie the Prepper"
3. Click "Actions" → "+ Add Action" → "From OpenAPI"
4. Paste the content of `/mnt/raid1/GitHub/GetPenn.ie/openapi/pennie-backend-openapi.json`
5. Save

**Test:** Ask Pennie "What DevOps projects do we have?" - She should return all 26 projects.
